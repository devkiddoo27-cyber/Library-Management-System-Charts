# Library Management System Database Architecture
Charts created for Library Management System Database

## Project Overview
Designed and implemented schema through entity relationship diagram for Library Management System Database and data flow model as part of graduate level Database Systems course (CSC 540) at Southern Connecticut State University.

This system manages member and administrative accounts, books/authors/publishers within the library system, book rental activity, book ratings, and book cataloging.

##ERD Model: displays the relational entities, primary and foreign keys, data constraints, and cardinalities between entities.

##Data Flow Diagram: displays the flow of data throughout the application from tracking member searches, book requests and loans, ratings, creating a profile, and the corresponding database updates. 

##Technical Stack and Skills Demonstrated 
- **Database System:** MySQL / Relational Database Design
- **Architecture Tools:** Mermaid JS, Data Modeling
- **Key Concepts:** Database Normalization, Foreign Key Constraints, Transaction Integrity, Data Validation
